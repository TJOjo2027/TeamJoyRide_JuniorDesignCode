## 🚀 Project Overview
**Team Joy Ride** is an electromechanical system designed, integrated, and validated as part of Baylor University’s Junior Design engineering coursework. The project combines custom hardware assembly, breadboard-to-microcontroller wiring, stepper/servo motor control, and optimized firmware loops to reliably execute pick-and-place routines.

## ⚙️ Systems Engineering & Firmware Contributions
As the **Systems Engineering Lead**, my core responsibilities and achievements included:
* **Firmware Optimization:** Refined core execution loops, successfully reducing firmware runtime by **32% (from 46s down to 31s)** through algorithmic streamlining.
* **Cross-Functional Integration:** Managed the hardware/software interfaces bridging mechanical actuators, stepper motors, servo grip controls, and microcontroller logic.
* **Requirements & Workflow Management:** Handled system-level integration testing, component layout on breadboards and structural frames, and debugging hardware-software synchronization issues under tight presentation deadlines.

## 🛠️ Technical Stack & Components
* **Microcontroller & Prototyping:** Arduino / Custom Breadboard Circuits
* **Actuation:** Stepper motors, servo-controlled mechanical claw/grabber
* **Language & Control:** C / C++ (Firmware architecture and timing control)
* **Hardware Interfacing:** Power regulation circuits, motor drivers, limit switches
